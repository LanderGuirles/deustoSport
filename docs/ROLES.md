# Roles SCRUM — Grupo 8

Para el desarrollo de este proyecto se han definido los siguientes roles siguiendo la metodología SCRUM:

| Rol | Persona/Entidad | Responsabilidades |
|-----|-----------------|-------------------|
| **Product Owner** | Lander | Definición de requisitos, priorización del backlog y validación de entregables. |
| **Scrum Master** | Gemini CLI (AI) | Facilitador del proceso, gestión de impedimentos y mantenimiento de la calidad técnica. |
| **Development Team** | Gemini CLI & Lander | Implementación de código, diseño de arquitectura, base de datos y testing. |

---

## Seguimiento del Progreso

El equipo utiliza una metodología ágil con:
- **Daily Stand-ups:** Resúmenes de actividad diarios documentados en los mensajes de commit.
- **Sprint Reviews:** Validación de funcionalidades con el Product Owner tras cada cambio significativo.
- **Continuous Integration:** Uso de GitHub Actions para validar cada push al repositorio.
